# 第一版遊戲規劃與後續方向

## 本次已實作

- 學生對象：國中生；原創題目示範，涵蓋常見字彙、現在進行式、短文細節與方向聽力。
- 風格：鼠尾草綠、暖金與霧藍的奇幻浮空島，原創向量場景與狐狸夥伴。透過地圖選點探索，而非自由行走。
- 核心循環：選擇地標 → 狐狸移動 → 互動解題或配對 → 繁中解析／水晶動畫 → 保存進度 → 解鎖下一區。
- 五區：晨光森林（單字）、星語溪谷（配對）、月影遺跡（文法）、天空樹屋（閱讀）、水晶之巔（聽力）。
- 技術：Vite + 原生 ES modules、DOM 互動、SVG 地圖、CSS 動畫、Web Audio 合成；支援靜態 Cloudflare Pages。
- 題庫與進度：JSON／CSV 預覽及驗證後套用、暱稱分開保存、本機排行榜、成績 JSON 匯出。
- 驗收：完整闖關、錯題解析、不重複計分、配對錯誤與成功、跨尺寸、匯入及保存皆有自動化檢查。

## 後續建議順序（本次未實作）

1. 與教師確認實際教材與題量，擴充內容並由教師審題；為聽力準備合法錄音，減少對裝置語音的依賴。
2. 實機驗證 iOS Safari、Android、平板及教室電腦的觸控與聲音；完成教師試用回饋。
3. Cloudflare Workers＋D1 已實作成績回傳、去重與待同步佇列，老師頁提供受保護的班級排行榜；待帳戶授權後做真實雲端驗收。
4. 依需求新增測驗模式、角色自由行走、更多任務、教師後台及較完整的無障礙替代介面。
5. 經使用者授權後部署 Cloudflare Pages，確認線上產物；不把本機成功視為已部署。
